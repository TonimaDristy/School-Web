 📝 Description

A full-stack web application designed to manage school operations efficiently,  
including user roles, authentication, and admission handling.

 🛠 Tech Stack
- 🖥 Frontend: HTML, CSS, JavaScript  
- ⚙ Backend: PHP  
- 🗄 Database: MySQL  
- 🧰 Environment: XAMPP  
- 📊 DB Tool: phpMyAdmin  

🔐 Key Features
- Role-based login (Student, Teacher, Head Teacher, Admin)  
- Secure password hashing and verification  
- Session-based authentication  
- Protected dashboard  
- Admission application form (stored in database)
