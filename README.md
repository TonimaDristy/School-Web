# 🎓 Luminary School – Full-Stack School Management System

<p align="center">
  <img src="https://github.com/TonimaDristy/School-Web/raw/main/Home.jpg" width="60%" />

A modern **full-stack web application** built to streamline and manage school operations efficiently.  
From role-based access control to secure authentication and admission handling — this system is designed to simplify administrative and academic workflows.

## 🛠 Tech Stack

- 🖥 Frontend: HTML, CSS, JavaScript  
- ⚙ Backend: PHP  
- 🗄 Database: MySQL  
- 🧰 Environment: XAMPP  
- 📊 DB Tool: phpMyAdmin  

---


### Database Setup 
- Open **phpMyAdmin**
- Create a database: `school_system`
- Import the `.sql` file for applications and users.
